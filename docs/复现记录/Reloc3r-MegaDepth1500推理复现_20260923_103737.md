## 指标定义

| 指标 | 含义 |
|---|---|
| AUC@τ | 以 τ∈{5,10,20}° 为阈值，对每对图像取 max(旋转角误差, 平移方向角误差) 的 accuracy 曲线下面积，归一化到 [0,1]（reloc3r/utils/metric.py: error_auc） |
| 旋转角误差 | 预测 R 与 GT R 之差的 Rodrigues 模长（度） |
| 平移方向角误差 | 预测 t 方向与 GT t 方向的夹角（度），不含尺度 |
| 1500 pairs | MegaDepth1500 测试对总数（场景 0015: 600 对，0022: 900 对，共 806 张去畸变图像） |

## 复现中确认的事实

- amp=1（fp16）为 README 推荐的无损加速选项，本次在 5090 上实测结果仍与论文一致。
- `reloc3r/datasets/__init__.py` 会连带 import cambridge/sevenscenes 等评测数据集模块（需 h5py、imagesize），但 MegaDepth1500 评测本身只读 `./data/megadepth1500`。
- torch 2.7 下 `inference_relpose` 的 `torch.cuda.amp.autocast` 仅触发 FutureWarning，不影响运行。

## 追加：curope CUDA RoPE 编译（2026-09-23 15:45 CST）

- torch 2.7 兼容性修复一处：croco/models/curope/kernels.cu:101 `tokens.type()` → `tokens.scalar_type()`（AT_DISPATCH 宏自 torch 2.x 起要求 ScalarType，属上游 croco 对新版 torch 的通病，改动仅 1 行，留在 croco submodule 工作区）。
